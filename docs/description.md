# Описание

Приложение представляет собой исполняемый jar файл - rest web service. Стек технологий Java 21, Spring Boot. Приложение работает на встроенном в SptingBoot сервере Undertow. Номер порта должен задаваться в конфигурационном файле по умолчанию порт должен быть 8088. Приложение делается для запуска на серверной инфраструктуре  в headless режиме.

У этого приложения есть три API метода:
1. MakeSnapshot
2. MakePDF
3. MakePPTX

Каждый метод вызывается методом POST на вход принимает JSON в котором содержится URL страницы которую надо конвертировать в MHTML, PDF или PPTX.

Для рендеринга страницы используется встроенный/embeded chromium браузер и selenium. Также есть возвожность подключить внешний браузер на базе chromium и chrome driver. Все настроки парараметров отрисовки страниц, параметра запуска chrome driverи брайзера должны храниться в файле конфигурации.

Настройки должны храниться в конфигурационном файле. По умолчанию конфигурационный файл берется из ресурсов Jar файла. Есть возможность передать путь к внешнему конфигурационному файлу как парамеметр (например  --config=/path/to/config.properties). Если передается внешний файл, то берутся настроки из него.

У приложения должно настраиваться логирование через конфигурационные файлы. По умолчанию логирование ложно осуществляться в консоль.
Сохрани бизнес требования в формате markdown в в папке ocapp.

Мотоды и классы должны выть покрыты тестами на 100%
